# Shot Format Templates

Use these templates as the base for every shot in your storyboard. Replace bracketed placeholders with your specifics.

## Establishing Shot (EST)

```
Wide establishing shot of [location].
[Architectural details]. [Time of day] light fills the space.
[Atmospheric detail — dust motes, steam, etc.].
Slow push in toward [focal point].
Cinematic, [film stock], 8K quality.
Duration: [N]s.
```

## Wide Shot (W)

```
Wide shot of [subject] in [location].
[Subject description] [action].
[Environment details visible].
[Lighting quality].
Camera static or slow pan.
Commercial quality, 8K.
Duration: [N]s.
```

## Medium Shot (MS)

```
Medium shot framing [subject] from [waist/knees].
[Subject] [action].
[Background context visible but not dominant].
[Lighting: key/fill/rim description].
Shallow depth of field, subject sharp, background softly blurred.
Duration: [N]s.
```

## Close-Up (CU)

```
Close-up of [subject face/product].
[Feature detail: eyes, lips, texture, logo].
[Emotion or intent].
[Lighting: soft/dramatic/natural].
Extreme shallow depth of field.
Cinematic, film grain, 8K.
Duration: [N]s.
```

## Extreme Close-Up (ECU)

```
Extreme close-up macro shot of [detail].
[Surface texture visible: skin pores, material weave, condensation].
[Lighting: directional to emphasize texture].
Depth of field so shallow only [specific element] is in focus.
Product photography quality, 8K.
Duration: [N]s.
```

## Tracking Shot (TRACK)

```
Tracking shot following [subject] as they [move through location].
Camera stays [distance] from subject.
[Background elements pass by].
[Lighting shifts naturally as subject moves].
Smooth, steady movement.
Cinematic, 8K.
Duration: [N]s.
```

## Orbital Shot (ORB)

```
Orbital shot rotating 360° around [subject/product].
Subject remains centered and static.
[Background scrolls around subject].
[Lighting stays consistent throughout rotation].
Hero shot, dramatic, 8K.
Duration: [N]s.
```

## Push In (PUSH)

```
Slow push in toward [subject].
[Subject] [action or expression].
Background compresses as camera approaches.
[Lighting detail].
Tension building, cinematic.
Duration: [N]s.
```

## Pull Out (PULL)

```
Pull out from close detail of [subject] to reveal [full scene].
Starts as [extreme close-up detail].
Reveals [context: location, other characters, environment].
[Lighting quality].
Reveal moment, cinematic.
Duration: [N]s.
```

## Low Angle (LA)

```
Low angle hero shot looking up at [subject].
[Subject] appears [powerful/imposing/heroic].
[Sky/background above subject].
[Lighting: backlit/side-lit for silhouette effect].
Heroic composition, 8K.
Duration: [N]s.
```

## High Angle (HA)

```
High angle shot looking down at [subject/location].
[Subject] appears [small/vulnerable/intimate].
[Layout or pattern visible from above].
[Soft, diffused lighting].
Documentary style, 8K.
Duration: [N]s.
```

## POV Shot (POV)

```
Point-of-view shot from [subject]'s perspective.
[What they see: hands, path ahead, object in view].
[Natural head movement, slight sway].
[Lighting as seen through their eyes].
Immersive, documentary style.
Duration: [N]s.
```

## Insert Shot (INS)

```
Cutaway insert of [detail object/action].
[Close framing, isolated from main action].
[Transition function: emphasizes emotion, shows information].
Quick, punchy edit.
Duration: [N]s.
```

## Over-the-Shoulder (OTS)

```
Over-the-shoulder shot from behind [character A], focusing on [character B/product].
[Character A's shoulder/head visible in foreground, softly out of focus].
[Character B] [action/expression].
[Environment between them visible].
Dialogue scene style, 8K.
Duration: [N]s.
```

## Aerial Shot (AER)

```
Aerial/drone shot sweeping over [location/landscape].
[Geographic features, architecture, or natural elements].
[Time of day: golden hour for warm tones].
Smooth, flowing camera movement.
Epic scale, cinematic.
Duration: [N]s.
```

## Whip Pan Transition

```
Fast whip pan from [left/right] to [right/left].
[Blurred motion transition].
Land on [new subject/location].
Dynamic, energetic.
Duration: [N]s.
```

## Match Cut Template

```
[Shot A ends on: specific visual element — circle, line, color].
HARD CUT TO:
[Shot B begins with: matching visual element — same shape, line, or color in new context].
Thematic visual bridge between scenes.
```
