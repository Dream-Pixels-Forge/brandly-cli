# Mecha Types Reference

Common mecha categories for campaign visualization.

## Industrial Robots

**Purpose:** Manufacturing, assembly, logistics
**Key elements:**
- Heavy construction
- Tool attachments
- Warning labels
- Maintenance access points
- Safety features
- Functional design

**Visual style:**
- Utilitarian
- Weathered
- Work-worn
- Practical

**Prompt template:**
```
Industrial robot, heavy construction,
visible hydraulics and joints,
warning labels and safety markings,
factory setting, documentary style.
```

## Combat Mecha

**Purpose:** Defense, warfare, protection
**Key elements:**
- Armor plating
- Weapon mounts
- Sensor arrays
- Damage effects
- Tactical positioning
- Aggressive stance

**Visual style:**
- Intimidating
- Battle-worn
- Militaristic
- Advanced technology

**Prompt template:**
```
Combat mecha, armored plating,
weapon systems visible,
battle damage and scorch marks,
tactical stance, sci-fi military style.
```

## Service Androids

**Purpose:** Customer service, hospitality, assistance
**Key elements:**
- Human-like proportions
- Friendly interfaces
- Tool storage
- Clear status indicators
- Soft edges
- Approachable design

**Visual style:**
- Friendly
- Clean
- Helpful
- Modern

**Prompt template:**
```
Service android, humanoid form,
friendly interface panels,
clean design with soft edges,
hospitality setting, commercial style.
```

## Exoskeletons

**Purpose:** Enhancement, augmentation, support
**Key elements:**
- Harness system
- Joint articulation
- Power units
- Control interfaces
- Size relative to user
- Wearability focus

**Visual style:**
- Lightweight
- Functional
- Enhancing
- Personal tech

**Prompt template:**
```
Exoskeleton suit, wearable design,
joint articulation visible,
power units and controls,
human-scale integration, tech product style.
```

**Key elements:**
- Medical equipment
- Emergency lights
- Rescue tools
- Accessibility features
- Clear identification
- Speed and efficiency

**Visual style:**
- Professional
- Urgent
- Capable
- Trustworthy

**Prompt template:**
```
Medical rescue mecha, emergency equipment,
visible medical bays and tools,

**Key elements:**

- Weather resistance
- Field adaptation
- Efficiency focus

**Visual style:**
- Rugged
- Practical
- Weathered
- Productive

**Prompt template:**
```

```

## Exploration

**Purpose:** Space, deep sea, extreme environments
**Key elements:**
- Environmental sealing
- Advanced sensors
- Mobility systems
- Power efficiency
- Communication arrays
- Survival gear

**Visual style:**
- Advanced
- Self-sufficient
- High-tech
- Adventure-ready

**Prompt template:**
```
