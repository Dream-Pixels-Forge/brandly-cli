# Technical Diagrams Reference

Visual references for mecha design documentation.

## Orthographic Views

Standard technical drawing format:

### Front View
- Full height visible
- Symmetry check
- Proportions
- Component placement

### Side View
- Depth and thickness
- Profile silhouette
- Joint visibility
- Attachment points

### Top View
- Overall footprint
- Width distribution
- Center of gravity
- Surface details

## Wireframe Representation

For technical presentations:

- Clean line work
- Internal structure visible
- Material callouts
- Dimension annotations

## Material Callouts

Document these elements:

### Primary Materials
- Armor type: [Steel/Composite/Ceramic]
- Finish: [Matte/Glossy/Metallic]
- Weathering level: [None/Minor/Moderate/Severe]

### Secondary Materials
- Wiring: [Exposed/Concealed]
- Joints: [Hydraulic/Pneumatic/Electric]
- Sensors: [Lidar/Camera/Radar]

## Dimension Annotation

Include these measurements:

```
Height: [X] meters
Width: [Y] meters
Depth: [Z] meters
Weight: [W] tons
Power output: [P] kW
```

## Color Coding Legend

Use consistent color coding:

| Color | Meaning |
|-------|---------|
| Blue | Structural elements |
| Red | Weapon systems |
| Green | Power systems |
| Yellow | Warning zones |
| White | Sensor arrays |
| Gray | Armor plating |

## Panel Line Details

Document visible seams:

- Maintenance access panels
- Armor seam lines
- Joint connections
- Service hatches
