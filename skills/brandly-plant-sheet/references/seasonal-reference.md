# Seasonal Reference

Seasonal changes for plant photography.

## Spring

### Visual Characteristics
- Fresh green growth
- Flower buds and blooms
- Shorter grass
- Bright, fresh lighting
- Rain elements possible

### Plants in Bloom
- Cherry blossoms
- Tulips
- Daffodils
- Magnolia
- Lilac

### Prompt Tags
```
spring, fresh growth, blooming,
soft morning light, dew drops,
renewal, vibrant colors
```

### Scene Elements
- New leaves emerging
- Flowering branches
- Small birds/nesting
- Gentle rain
- Melting snow patches

## Summer

### Visual Characteristics
- Full, lush foliage
- Deep green colors
- Bright, harsh sunlight
- Long shadows
- Active pollinators

### Plants at Peak
- Sunflowers
- Roses
- Lavender
- Herbs in flower
- Vegetable gardens

### Prompt Tags
```
summer, full growth, lush green,
bright sunlight, warm tones,
active garden, pollinators
```

### Scene Elements
- Bees and butterflies
- Fruit development
- Hot sun effects
- Garden tools
- Harvest preparation

## Autumn

### Visual Characteristics
- Color change (red, orange, gold)
- Falling leaves
- Cooler lighting
- Longer shadows
- Harvest atmosphere

### Color Palette
- Crimson reds
- Golden yellows
- Deep oranges
- Brown tones
- Purple accents

### Prompt Tags
```
autumn, fall colors, golden light,
falling leaves, harvest season,
crisp air, warm tones
```

### Scene Elements
- Leaf piles
- Harvest baskets
- Migration birds
- Frost mornings
- Pumpkin patches

## Winter

### Visual Characteristics
- Bare branches
- Snow and ice
- Dormant plants
- Soft, diffused light
- Minimalist composition

### Evergreen Elements
- Pine trees
- Holly berries
- Winter jasmine
- Cranberry bushes

### Prompt Tags
```
winter, snow covered, bare branches,
quiet stillness, cold light,
dormant garden, seasonal rest
```

### Scene Elements
- Snow accumulation
- Ice formations
- Winter birds
- Frost patterns
- Bare branches silhouettes

## Seasonal Transitions

### Late Winter to Spring
- First buds appearing
- Snow melting
- Early crocuses
- Lengthening days

### Summer to Autumn
- First color changes
- Harvest begins
- Cooling temperatures
- Migration starts

### Autumn to Winter
- Last leaves falling
- First frost
- Plant dieback
- Shorter days

## Photography Tips by Season

| Season | Best Time | Lighting | Focus |
|--------|-----------|----------|-------|
| Spring | Morning | Soft, diffused | Buds and blooms |
| Summer | Early morning/later afternoon | Warm, directional | Full growth |
| Autumn | Golden hour | Warm, low angle | Color changes |
| Winter | Overcast days | Even, soft | Structure and form |

## Care Requirements by Season

### Spring Care
- Start fertilizing
- Prune dead growth
- Plant new specimens
- Increase watering

### Summer Care
- Regular watering
- Monitor pests
- Deadhead flowers
- Support tall growth

### Autumn Care
- Prepare for dormancy
- Reduce watering
- Plant spring bulbs
- Clean up debris

### Winter Care
- Protect tender plants
- Plan next season
- Maintain tools
- Study plant catalogs
