# Prompt Variations for Mecha Sheets

Different prompt formats for various mecha types.

## Basic Prompt Format

```
[Mecha designation] mechanical unit.
[Body plan] with [materials description].
[Color scheme] with [weathering details].
[Sensor details] visible.
[Lighting effects] active.
[Style descriptor].
Quality: [8K/Technical illustration/Photorealistic]
```

## By Mecha Type

### Industrial Robot
```
Industrial robot [designation], heavy construction,
visible hydraulics and joints,
warning labels, [factory/warehouse] setting,
documentary photography style.
```

### Combat Mecha
```
Combat mecha [designation], armored plating,
weapon mounts visible, battle damage,
tactical stance, [battlefield/warzone] setting,
sci-fi military style.
```

### Service Android
```
Service android [designation], humanoid form,
friendly interface panels, clean design,
[hospitality/retail] setting,
commercial product style.
```

### Exoskeleton
```
Exoskeleton suit, wearable design,
joint articulation visible, power units,
[worker/user] wearing it, tech product style.
```

### Exploration Unit
```
Exploration mecha [designation], advanced sensors,
environmental sealing, [space/alien planet] setting,
scientific equipment, concept art style.
```

## View Types

### Hero Shot
```
Hero shot of [mecha], dynamic angle,
[lighting style], dramatic pose,
cinematic quality.
```

### Technical Render
```
Technical render of [mecha], wireframe overlay,
material callouts, dimension annotations,
engineering diagram style.
```

### Action Shot
```
[Meche] in [action], motion blur,
[dust/debris] effects, dynamic pose,
action photography style.
```

### Detail Close-up
```
Close-up of [mecha part], showing [detail],
material texture visible, studio lighting,
macro photography style.
```

## Lighting Styles

### Studio
```
Studio lighting, clean background,
product showcase, commercial quality
```

### Industrial
```
Factory lighting, practical lights,
gritty atmosphere, documentary style
```

### Combat
```
Battle lighting, muzzle flashes,
explosions, dramatic contrast
```

### Sci-Fi
```
Neon lighting, holographic displays,
futuristic atmosphere, concept art
```

## Tips

- Use consistent naming conventions
- Document exact specifications
- Include scale references
- Specify material finishes
- Match lighting to scene type
