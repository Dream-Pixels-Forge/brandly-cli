# Lighting Presets Reference

Complete guide to lighting setups for video generation.

## Golden Hour

**Best for:** Emotional scenes, warm tone
**Description:** Warm late-afternoon sun
**Tags:** amber light, long shadows, sun flare
**Prompt usage:**
```
golden hour lighting, warm amber tones,
long dramatic shadows, sun flare effects
```

## Blue Hour

**Best for:** Moody scenes, urban nights
**Description:** Cool twilight period
**Tags:** blue ambient, street lamps, soft fill
**Prompt usage:**
```
blue hour lighting, cool blue ambient,
street lamps glowing, soft city fill
```

## Studio

**Best for:** Product shots, commercials
**Description:** Clean commercial lighting
**Tags:** soft key, fill opposite, rim light
**Prompt usage:**
```
studio lighting, soft key light,
fill light opposite, rim light separation,
clean commercial look
```

## Neon

**Best for:** Urban night, cyberpunk
**Description:** Urban night lighting
**Tags:** cyan/magenta reflections, wet bounce
**Prompt usage:**
```
neon lighting, cyan and magenta reflections,
wet surface bounce, urban night atmosphere
```

## Natural

**Best for:** Authentic, documentary
**Description:** Soft daylight
**Tags:** window light, diffused, gentle shadows
**Prompt usage:**
```
natural lighting, soft window light,
diffused illumination, gentle shadows,
authentic feel
```

## Dramatic

**Best for:** High contrast, moody
**Description:** High contrast lighting
**Tags:** side lighting, deep shadows, chiaroscuro
**Prompt usage:**
```
dramatic lighting, side lighting,
deep shadows, chiaroscuro effect,
high contrast mood
```

## Product Studio

**Best for:** Product photography, e-commerce
**Description:** Clean product presentation
**Tags:** clean white background, sharp focus
**Prompt usage:**
```
product studio lighting, clean white background,
sharp focus, even illumination,
commercial product quality
```

## Night

**Best for:** Evening scenes, atmosphere
**Description:** Practical lights
**Tags:** moonlight blue, street lights, depth
**Prompt usage:**
```
night lighting, moonlight blue tones,
street lights creating depth,
practical sources, atmospheric
```

---

## Lighting Combinations

| Scene | Recommended Lighting | Tags |
|-------|---------------------|------|
| Product reveal | Product Studio + Natural | clean, sharp, bright |
| Emotional story | Golden Hour + Studio | warm, emotional, soft |
| Urban night | Neon + Blue Hour | cool, vibrant, dynamic |
| Documentary | Natural | authentic, real, soft |
| Luxury product | Studio + Dramatic | premium, refined, contrast |
| Action sequence | Dramatic + Natural | high energy, dynamic |

---

## Prompt Integration

Include lighting in your prompts:

```
[Scene description], [lighting preset] lighting,
[style] style, [quality] quality.
```

Example:
```
Woman walking through garden, golden hour lighting,
cinematic style, 8K quality.
```
