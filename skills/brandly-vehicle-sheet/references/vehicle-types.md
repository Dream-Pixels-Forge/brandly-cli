# Vehicle Types Reference

Common vehicle categories for campaign visualization.

## Luxury Sedan

**Focus:** Elegance, comfort, status
**Key elements:**
- Sleek lines
- Premium materials
- Refined details
- Quiet, composed presence
- Executive styling

**Visual style:**
- Polished, refined
- Professional setting
- Subtle luxury
- Calm demeanor

**Prompt template:**
```
Luxury sedan, elegant lines,
premium finish, executive presence,
sophisticated setting, automotive photography.
```

## Sports Car

**Focus:** Performance, excitement, speed
**Key elements:**
- Aggressive stance
- Aerodynamic features
- Large wheels
- Low profile
- Dynamic lighting

**Visual style:**
- Energetic, exciting
- Dynamic poses
- Speed imagery
- High-contrast lighting

**Prompt template:**
```
Sports car, aggressive stance,
aerodynamic design, performance wheels,
dynamic lighting, automotive action style.
```

## SUV/Adventure

**Focus:** Capability, space, versatility
**Key elements:**
- Rugged styling
- Roof rails
- All-terrain tires
- High ground clearance
- Family-friendly

**Visual style:**
- Capable, ready
- Outdoor settings
- Adventure theme
- Natural lighting

**Prompt template:**
```
SUV adventure vehicle, rugged styling,
roof rails, all-terrain tires,
outdoor setting, family adventure style.
```

## Electric Vehicle

**Focus:** Technology, sustainability, innovation
**Key elements:**
- Aerodynamic shape
- LED lighting
- Minimal grille
- Tech displays
- Futuristic details

**Visual style:**
- Clean, modern
- Tech-forward
- Sustainable messaging
- Future aesthetic

**Prompt template:**
```
Electric vehicle, aerodynamic design,
LED lighting, minimalist front,
tech-forward setting, sustainable future style.
```

## Classic/Vintage

**Focus:** Heritage, nostalgia, craftsmanship
**Key elements:**
- Period-correct design
- Chrome details
- Two-tone paint
- Whitewall tires
- Interior details

**Visual style:**
- Nostalgic, timeless
- Museum or garage setting
- Restoration quality
- Heritage photography

**Prompt template:**
```
Classic car, vintage design,
chrome details, two-tone paint,
restored condition, heritage photography style.
```

## Truck/Pickup

**Focus:** Utility, strength, work capability
**Key elements:**
- Bed/cargo area
- Towing capability
- Rugged build
- Work-ready stance
- Functional design

**Visual style:**
- Practical, capable
- Work or recreational settings
- Rugged environments
- Action-oriented

**Prompt template:**
```
Pickup truck, work-ready stance,
cargo bed, towing capability,
rugged setting, utility photography style.
```

## Hatchback/Compact

**Focus:** Efficiency, urban mobility, practicality
**Key elements:**
- Compact proportions
- Efficient design
- Urban-friendly size
- Practical features
- Accessible styling

**Visual style:**
- Modern, practical
- City settings
- Everyday use
- Accessible luxury

**Prompt template:**
```
Compact hatchback, efficient design,

```

## Convertible

**Focus:** Freedom, lifestyle, enjoyment
**Key elements:**
- Retractable roof
- Open-air experience
- Sporty stance
- Premium interior
- Summer lifestyle

**Visual style:**
- Free, joyful
- Coastal or scenic roads
- Summer atmosphere
- Lifestyle photography

**Prompt template:**
```

lifestyle photography, freedom theme.
```

- Commercial photography
