# Product Categories Reference

Common product types and their key visual elements.

## Electronics

**Focus:** Sleek design, screens, ports, buttons
**Key elements:**
- Clean lines
- Metallic/plastic materials
- Screen displays
- Brand logos
- Port visibility

**Prompt tips:**
- Use studio lighting for clean backgrounds
- Show multiple angles
- Highlight screen/display when relevant

## Beauty/Cosmetics

**Focus:** Packaging, texture, application
**Key elements:**
- Bottle/jar design
- Product texture
- Color accuracy
- Luxury materials
- Application tools

**Prompt tips:**
- Use soft, diffused lighting
- Show product on skin when applicable
- Highlight texture and finish

## Fashion/Accessories

**Focus:** Materials, craftsmanship, details
**Key elements:**
- Fabric texture
- Stitching details
- Hardware (zippers, buttons)
- Branding
- Fit and drape

**Prompt tips:**
- Use lifestyle or studio settings
- Show product being worn
- Highlight material qualities

## Food/Beverage

**Focus:** Freshness, appeal, presentation
**Key elements:**
- Texture visibility
- Steam/freshness indicators
- Plating/presentation
- Color vibrancy
- Context (table setting)

**Prompt tips:**
- Use natural lighting
- Show steam/freshness
- Include context props

## Home/Lifestyle

**Focus:** Functionality, aesthetics, space
**Key elements:**
- Product in use
- Room context
- Scale reference
- Material textures
- Color coordination

**Prompt tips:**
- Show product in realistic settings
- Include lifestyle context
- Demonstrate functionality

## Automotive Parts

**Focus:** Precision, materials, engineering
**Key elements:**
- Technical details
- Material finishes
- Assembly context
- Performance indicators

**Prompt tips:**
- Use industrial lighting
- Show technical details
- Include scale/context
