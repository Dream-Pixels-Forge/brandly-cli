# Common Character Types

Quick reference for popular character archetypes in campaigns.

## Product Model

**Use for:** Fashion, beauty, lifestyle products
**Key elements:**
- Clean, versatile appearance
- Neutral expressions
- Professional wardrobe
- Photogenic features
- Multiple outfit variations

**Prompt example:**
```
Professional model, 25-30 years old, clean features,
wearing [product], studio lighting,
commercial photography style.
```

## Executive/Professional

**Use for:** Corporate, B2B, technology
**Key elements:**
- Business attire
- Confident posture
- Age: 30-50
- Clean, polished appearance
- Trustworthy expression

**Prompt example:**
```
Business professional, 40 years old,
wearing dark suit, confident stance,
corporate office background,
cinematic lighting.
```

## Youth/Gen Z

**Use for:** Social media, trends, lifestyle
**Key elements:**
- Trendy streetwear
- Natural, relatable look
- Age: 18-28
- Casual posture
- Authentic expressions

**Prompt example:**
```
Young adult, 22 years old, casual streetwear,
natural lighting, authentic expression,
lifestyle photography style.
```

## Luxury/High-End

**Use for:** Premium products, fashion, jewelry
**Key elements:**
- Elegant wardrobe
- Refined features
- Sophisticated posture
- High-fashion aesthetic
- Minimal, clean styling

**Prompt example:**
```
Elegant figure, high fashion aesthetic,
wearing luxury brand, minimal background,
editorial photography style.
```

## Diversity Notes

Always consider:
- Ethnic diversity in casting
- Age range appropriateness
- Body type representation
- Accessibility considerations
- Cultural authenticity
