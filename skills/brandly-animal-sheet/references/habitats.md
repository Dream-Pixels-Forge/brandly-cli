# Habitat Contexts

Natural and contextual environments for animal photography.

## Forest/Woodland

**Animals:** Deer, foxes, wolves, owls, squirrels
**Elements:**
- Tree canopy
- Dappled light
- Forest floor
- Moss, ferns
- Fallen logs

**Prompt tags:**
```
forest setting, dappled sunlight,
woodland atmosphere, natural habitat,
wildlife photography
```

## Savanna/Grassland

**Animals:** Lions, elephants, zebras, giraffes
**Elements:**
- Open plains
- Acacia trees
- Golden grass
- Wide skies
- Dust effects

**Prompt tags:**
```
savanna landscape, golden hour,
open plains, African wilderness,
documentary style
```

## Desert

**Animals:** Camels, reptiles, foxes, scorpions
**Elements:**
- Sand dunes
- Rock formations
- Sparse vegetation
- Harsh sunlight
- Temperature effects

**Prompt tags:**
```
desert environment, arid landscape,
sand and rock, extreme conditions,
survival photography
```

## Ocean/Marine

**Animals:** Dolphins, whales, sea turtles, sharks
**Elements:**
- Water clarity
- Coral reefs
- Sun rays through water
- Marine vegetation
- Surface vs underwater

**Prompt tags:**
```
underwater photography, marine life,
oceanic setting, crystal clear water,
National Geographic style
```

## Arctic/Antarctic

**Animals:** Polar bears, penguins, seals, arctic foxes
**Elements:**
- Ice and snow
- Glaciers
- Aurora effects
- Extreme cold
- Minimal vegetation

**Prompt tags:**
```
arctic environment, ice and snow,
extreme cold, northern lights,
wildlife documentary
```

## Urban

**Animals:** Pigeons, squirrels, raccoons, cats
**Elements:**
- Buildings
- Streets
- Parks
- Human interaction
- Neon/ambient light

**Prompt tags:**
```
urban wildlife, city environment,
human-animal interaction,
street photography
```

## Freshwater

**Animals:** Beavers, otters, frogs, fish
**Elements:**
- Lakes, rivers, streams
- Reeds and marshes
- Water reflections
- Amphibious settings

**Prompt tags:**
```
freshwater habitat, river or lake,
wetland environment, natural setting
```

## Conservation Notes

When creating animal content:
- Show animals in natural behaviors
- Respect wildlife boundaries
- Avoid staged or stressful situations
- Consider seasonal variations
- Document habitat conservation messages
