# Lock Strength by Asset Type

Not all assets need equal consistency. This guide maps the recommended anchor strength for every asset category.

## Anchor Strength Reference

| Level | Symbol | Use When | Regenerate If |
|-------|--------|----------|---------------|
| GOLD | 🔒 | Identity-critical, brand-critical | Any visible change |
| SILVER | 🔒 | Context-critical, repeated use | Lighting or major feature shift |
| BRONZE | 🔒 | Noticeable if wrong, occasional use | Obvious inconsistency |
| PLASTIC | ⚪ | Atmosphere, can vary freely | Never — variation is expected |

## Characters

| Element | Strength | Why |
|---------|----------|-----|
| Face / identity | 🔒 GOLD | Core of character recognition |
| Eye color | 🔒 GOLD | Impossible to hide if wrong |
| Hair color | 🔒 GOLD | First thing noticed |
| Hair style | 🔒 GOLD | Defines character silhouette |
| Skin tone | 🔒 GOLD | Fundamental to identity |
| Body type | 🔒 GOLD | Affects silhouette and presence |
| Distinctive features | 🔒 GOLD | Freckles, scars, mole patterns |
| Outfit | 🔒 SILVER | Can vary by scene, but must stay in palette |
| Accessories | 🔒 BRONZE | Can be scene-specific |
| Expression | ⚪ PLASTIC | Intentionally varies per shot |
| Age appearance | 🔒 SILVER | Should stay consistent range |

|---------|----------|-----|

| Floor material | 🔒 SILVER | Establishes space identity |

## Products

| Element | Strength | Why |
|---------|----------|-----|
| Overall shape | 🔒 GOLD | Brand identity depends on it |
| Primary color | 🔒 GOLD | Color is often the brand signal |
| Logo / text | 🔒 GOLD | Must be legible and correct |
| Material finish | 🔒 GOLD | Matte vs glossy changes perception |
| Size proportions | 🔒 GOLD | Wrong proportions = wrong product |
| Cap / lid detail | 🔒 SILVER | Part of the identity |
| Packaging | 🔒 SILVER | Important for unboxing context |
| Reflection behavior | 🔒 SILVER | Signals material quality |
| Background prop | ⚪ PLASTIC | Can vary by scene |
| Hand holding product | ⚪ PLASTIC | Different models acceptable |

## Quick Reference: What's Non-Negotiable

### Never Compromise (GOLD — must match exactly)
- Character face
- Character eye color
- Character hair color
- Product shape
- Product primary color
- Product logo/text

### Strongly Consistent (SILVER — should match, minor drift acceptable)
- Character outfit color palette
- Location wall color
- Location time of day
- Product material finish
- Key light direction
- Color temperature

### Flexible (BRONZE — consistency nice but not critical)
- Accessories and jewelry
- Decor items and props
- Secondary lighting
- Lens choice
- Background extras

### Intentionally Variable (PLASTIC — variation is desired)
- Facial expressions
- Body posture
- Weather conditions (if story requires)
- Background crowd density
- Shot-to-shot creative choices
