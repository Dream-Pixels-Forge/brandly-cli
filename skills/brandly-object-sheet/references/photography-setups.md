# Photography Setups

Lighting and camera setups for product photography.

## Studio Setup

**Best for:** Clean product shots, e-commerce
**Setup:**
- White seamless background
- Softbox lighting (key + fill)
- Rim light for separation
- Tripod for consistency

**Prompt template:**
```
Product photography, white background,
studio lighting, soft shadows,
clean presentation, commercial quality.
```

## Natural Light Setup

**Best for:** Lifestyle, food, organic products
**Setup:**
- Window light (north-facing preferred)
- Reflector for fill
- Natural backdrop
- Minimal props

**Prompt template:**
```
Natural lighting, window light,
soft shadows, lifestyle setting,
authentic atmosphere.
```

## Dramatic Setup

**Best for:** Luxury, premium products
**Setup:**
- Single key light
- Dark background
- High contrast
- Accent lights

**Prompt template:**
```
Dramatic lighting, high contrast,
dark background, premium feel,
cinematic quality.
```

## Macro Setup

**Best for:** Details, textures, small products
**Setup:**
- Macro lens
- Ring light or twin flash
- Stabilized platform
- Shallow depth of field

**Prompt template:**
```
Macro photography, extreme detail,
shallow depth of field,
texture visible, professional quality.
```

## Multi-Angle Series

Generate these standard angles:

1. **Front 3/4 view** — Hero shot
2. **Side profile** — Shows thickness/depth
3. **Top view** — Shows layout/arrangement
4. **Detail close-up** — Shows texture/materials
5. **Lifestyle shot** — Shows product in use
6. **Scale reference** — Shows size context
