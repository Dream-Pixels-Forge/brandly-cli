# Shot Angles Reference

Camera angles for automotive photography.

## Hero Shot (Front 3/4)

**Best for:** Main product showcase
**Angle:** Low, slightly from side
**Effect:** Dramatic, powerful
**Prompt tags:**
```
front three-quarter view, low angle,
hero shot, dynamic perspective,
automotive photography, 8K quality
```

## Side Profile

**Best for:** Showing length and stance
**Angle:** Eye-level, straight on
**Effect:** Clean, design-focused
**Prompt tags:**
```
side profile view, eye-level,
showing wheelbase and stance,
clean background, design photography
```

## Rear View

**Best for:** Taillights and trunk design
**Angle:** Slightly low, straight back
**Effect:** Bold, complete look
**Prompt tags:**
```
rear view, showing taillights,
trunk design, tailgate details,
automotive photography
```

## Low Angle (Hero)

**Best for:** Making car look powerful
**Angle:** Ground level, looking up
**Effect:** Intimidating, heroic
**Prompt tags:**
```
low angle hero shot, looking up,
powerful stance, dramatic perspective,
ground-level view
```

## High Angle (Bird's Eye)

**Best for:** Showing roof and overall shape
**Angle:** Directly above or slight angle
**Effect:** Complete overview
**Prompt tags:**
```
high angle view, bird's eye,
showing roofline and proportions,
aerial perspective
```

## Lighting by Angle

| Angle | Best Lighting | Effect |
|-------|--------------|--------|
| Front 3/4 | Side light | Shows lines and curves |
| Side Profile | Even light | Shows length and stance |
| Low Angle | Backlight | Dramatic silhouette |
| High Angle | Overhead | Shows roof design |
| Detail | Studio | Shows texture and finish |

## Background Recommendations

| Shot Type | Recommended Background |
|-----------|----------------------|
| Hero | Studio or clean road |
| Side Profile | Simple, uncluttered |
| Motion | Dynamic, blurred background |
| Detail | Neutral, non-distracting |
| Lifestyle | Context-appropriate setting |
