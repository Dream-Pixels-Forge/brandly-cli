# Prompt Variations for Plant Sheets

Different prompt formats for various plant types.

## Basic Prompt Format

```
Close-up of [plant name].
[Leaf description] with [color details].
[Flower details] in bloom.
[Garden/natural background].
[Lighting style].
[Style descriptor].
Quality: [8K/Macro/Commercial]
```

## By Plant Category

### Indoor Houseplant
```
[Potted plant] in [container style],
[indoor lighting], [shelf/table] placement,
[room] context, [plant] detail visible,
interior design photography.
```

### Garden Flower
```
[Garden setting], [flower type] in bloom,
[mixed planting scheme], [season] atmosphere,
[lighting style], garden photography.
```

### Tree/Shrub
```
[Tree/shrub] showing [features],
[bark/branch structure], [canopy] view,
[season] setting, [lighting],
landscape or botanical style.
```

### Succulent/Cactus
```
[Succulent type] close-up,
[form/texture] details,
[container] if applicable,
[desert/garden] context,
macro or product style.
```

## By Shot Type

### Portrait Shot
```
Portrait of [plant], showing [key features],
[lighting style], simple background,
botanical photography, 8K detail.
```

### Group Shot
```
Group of [plants] in [setting],
[mixed arrangement], natural lighting,
garden or greenhouse style.
```

### Detail Macro
```
Extreme close-up of [plant part],
[texture] visible, shallow depth of field,
macro photography, scientific detail.
```

### Lifestyle
```
[Plant] in [home/garden] setting,
[lifestyle context], natural light,
interior or garden photography.
```

### Seasonal
```
[Plant] in [season] setting,
[seasonal features], [lighting],
[theme] atmosphere.
```

## Growth Stage Variations

### Seedling
```
Young [plant] seedling,
[delicate] leaves, [pot/soil] visible,
starting growth, gentle lighting.
```

### Mature
```
Full-grown [plant], [flowering/fruited],
complete form, healthy appearance,
peak growth stage.
```

### Dried/Preserved
```
[Dried flower/seed pod],
[texture] emphasized, muted colors,
still life arrangement, artistic style.
```

## Tips

- Include scientific name for accuracy
- Match season to current growth stage
- Specify container if applicable
- Note light requirements visually
- Include scale context when helpful
