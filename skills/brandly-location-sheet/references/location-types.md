# Location Types Reference

Common location categories for campaign shoots.

## Modern Interior

**Use for:** Lifestyle, corporate, tech products
**Key elements:**
- Clean lines
- Neutral color palette
- Large windows
- Minimal furniture
- Natural materials (wood, stone)
- Contemporary lighting

**Prompt template:**
```
Modern [room type] with [materials],
large windows, natural light,
minimal furniture, contemporary design,
architectural photography style.
```

## Industrial Space

**Use for:** Tech, manufacturing, urban campaigns
**Key elements:**
- Exposed brick/concrete
- High ceilings
- Metal fixtures
- Large windows
- Open floor plan
- Raw materials

**Prompt template:**
```
Industrial [space type], exposed brick,
high ceilings, metal fixtures,
natural light from large windows,
urban aesthetic, documentary style.
```

## Luxury Setting

**Use for:** Premium products, fashion, high-end
**Key elements:**
- Premium materials (marble, gold)
- High-end furniture
- Statement lighting
- Art pieces
- Ample space
- Views

**Prompt template:**
```
Luxury [interior/exterior], marble accents,
high-end furnishings, statement lighting,
premium aesthetic, editorial style.
```

## Natural/Outdoor

**Use for:** Nature, travel, outdoor products
**Key elements:**
- Natural lighting
- Vegetation
- Sky visibility
- Terrain features
- Weather elements
- Natural materials

**Prompt template:**
```
Natural [setting], [vegetation/features],
golden hour lighting, [weather],
landscape photography style, cinematic quality.
```

## Studio Setup

**Use for:** Product-focused campaigns
**Key elements:**
- Seamless background
- Controlled lighting
- Clean environment
- No distractions
- Consistent setup

**Prompt template:**
```
Studio setup, seamless [color] background,
controlled lighting, clean environment,
product photography style, commercial quality.
```

## Historical/Period

**Use for:** Heritage brands, period pieces
**Key elements:**
- Period-appropriate architecture
- Vintage furnishings
- Appropriate lighting
- Authentic details
- Time period accuracy

**Prompt template:**
```
[Historical period] [interior/exterior],
period-appropriate details, [lighting style],
authentic to era, documentary style.
```

## Futuristic/Sci-Fi

**Use for:** Tech innovation, future products
**Key elements:**
- Sleek modern design
- Smart technology integration
- Clean lines
- Ambient lighting
- Minimalist aesthetic

**Prompt template:**
```
Futuristic [space], sleek design,
smart technology integration,
ambient lighting, sci-fi aesthetic,
concept visualization style.
```
