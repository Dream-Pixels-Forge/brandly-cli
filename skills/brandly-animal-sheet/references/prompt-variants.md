# Prompt Variations for Animal Sheets

Different prompt formats for various animal types.

## Basic Prompt Format

```
[Species] in [habitat].
[Physical description] with [color pattern].
[Natural behavior pose].
[Time of day] lighting, [lighting quality].
[Wildlife photography style].
Quality: [8K/National Geographic/Photorealistic]
```

## By Animal Type

### Domestic Pet
```
[Pet type] with [breed details],
[clean/healthy] appearance,
[playful/calm] expression,
[indoor/outdoor] setting,
commercial pet photography.
```

### Wildlife Portrait
```
Wildlife portrait of [species],
natural habitat background,
[behavior] pose,
golden hour lighting,
documentary photography style.
```

### Action Shot
```
[Species] in motion, [action],
[habitat] background,
motion blur effect,
dynamic composition,
action photography style.
```

### Family/Group
```
[Species] family group,
[parent and offspring],
natural social behavior,
[warm/soft] lighting,
documentary style.
```

### Macro/Insect
```
Macro photography of [insect],
extreme detail visible,
shallow depth of field,
natural lighting,
scientific illustration style.
```

### Fantasy Creature
```
Fantasy creature design,
hybrid of [species A] and [species B],
[mystical/magical] elements,
epic fantasy art style,
detailed anatomy.
```

## Seasonal Variations

### Spring
```
[Season] setting, fresh growth,
[bloom/birth] themes,
soft natural lighting,
renewal atmosphere
```

### Summer
```
[Season] setting, lush vegetation,
bright sunlight,
active wildlife,
vibrant colors
```

### Autumn
```
[Season] setting, fall colors,
golden light,
migration themes,
warm atmosphere
```

### Winter
```
[Season] setting, snow/ice,
cold lighting,
survival themes,
minimalist composition
```

## Tips

- Use scientific names for accuracy
- Match habitat to species naturally
- Include typical behaviors
- Consider seasonal changes
- Use appropriate photography styles
