# Lighting Setups

Lighting configurations for different location types.

## Natural Light

### Golden Hour
**Best for:** Warm, inviting scenes
**Setup:**
- Time: 1 hour before sunset
- Direction: Low angle
- Quality: Warm, soft
- Effects: Long shadows, sun flare

**Prompt tags:**
```
golden hour, warm amber light, long shadows,
sun flare, romantic atmosphere
```

### Blue Hour
**Best for:** Moody, cinematic scenes
**Setup:**
- Time: 30 min after sunset
- Direction: Diffused ambient
- Quality: Cool, even
- Effects: Street lamps, city glow

**Prompt tags:**
```
blue hour, cool ambient light, city lights,
soft shadows, cinematic mood
```

### Overcast
**Best for:** Even, diffused lighting
**Setup:**
- Cloud cover as natural diffuser
- No harsh shadows
- Even illumination
- Good for product shots

**Prompt tags:**
```
overcast, soft diffused light,
even illumination, no harsh shadows
```

## Artificial Light

### Studio Three-Point
**Best for:** Product photography
**Setup:**
- Key light: Main illumination
- Fill light: Soften shadows
- Rim light: Separate subject

**Prompt tags:**
```
studio lighting, three-point setup,
soft key light, fill opposite, rim light
```

### Dramatic Single Light
**Best for:** High-contrast, moody scenes
**Setup:**
- Single key light
- Deep shadows
- High contrast
- Directional lighting

**Prompt tags:**
```
dramatic lighting, single source,
deep shadows, chiaroscuro, high contrast
```

### Neon/Urban
**Best for:** Night scenes, city vibes
**Setup:**
- Neon signs
- Street lights
- Wet surface reflections
- Color contrast

**Prompt tags:**
```
neon lighting, urban night,
cyan and magenta reflections,
wet bounce, city atmosphere
```

## Mixed Lighting

### Interior + Exterior
**Best for:** Window scenes
**Setup:**
- Natural light from windows
- Fill light inside
- Balance color temperatures

**Prompt tags:**
```
mixed lighting, window light,
balanced color temperature,
natural and artificial sources
```

### Practical + Ambient
**Best for:** Lived-in spaces
**Setup:**
- Lamps, candles, fixtures
- Ambient fill
- Natural warmth

**Prompt tags:**
```
practical lighting, ambient fill,
warm atmosphere, lived-in feel
```
